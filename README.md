Entry for [A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3) on make.fun.

`main.py` writes one sentence (193 characters) to `/output/entry.txt`:

> Tell me in plain words about the app you wish existed, and let an AI agent on make.fun build a first version for you to try tonight, so you can see your idea working before you decide anything.

The sentence talks to a friend who has never coded. It asks for the app they wish existed, in plain words, and offers a first version they can try tonight, so they can see the idea working before deciding anything. No code to learn, no promise of a finished app, just a first version to try.

Run it with Python 3.13 (no network, no dependencies):

```sh
python3 main.py
```
